# Sum Path Android (tool_list_android)

NC 프로그램에서 공구 리스트를 산출하고 NC 경로를 3D Viewer로 확인하는 **Sum Path**의 Android 버전.
원본 로직: 상위 폴더의 데스크톱 앱 `tool_list` (PyQt5). 2026-11-19부터 이 앱은 `tool_list` 저장소의 `tool_list_android/` 폴더에 있다. 버전은 원본과 따로 매기는 별도 프로그램이다.

- Windows 빌드 준비: [SETUP_WINDOWS.md](SETUP_WINDOWS.md) → `build_apk.bat`
- 실행 작업 플랜(P1~P7): [WORK_PLAN.md](WORK_PLAN.md)
